# ISO 21972 Ontology - Core Pattern

Core organisational concepts for the ISO 21972 upper-level ontology for smart city indicators.

This pattern consists of the following classes:

- [Iso21972 Thing](ISO21972Thing.md)
This module defines the following properties:

- [iso21972DataProperty](../properties/iso21972DataProperty.md)
- [iso21972ObjectProperty](../properties/iso21972ObjectProperty.md)


The formal definition of this pattern is available in [TURTLE Syntax](../CorePattern.ttl).
